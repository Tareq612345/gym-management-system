An ultra-modern, responsive, dark-themed **Gym Management System and High-Conversion Public Website** built for fitness centers, athletic clubs, and gym operators.

---

## 🌟 Key Features

### 🏋️ 1. Modern Public Fitness Website
- **Energetic Hero Section:** High-octane athletic typography, live gym floor statistics, and quick call-to-actions.
- **Dynamic Class Schedule & Programs:** Interactive filtering by category (*Strength & Power*, *HIIT & MetCon*, *Boxing & Combat*, *Mobility & Recovery*) with average calorie burns, coach assignments, and trial booking.
- **Interactive Body Mass Index (BMI) Tool:** Instant calculation providing health classification, target advice, and custom fitness recommendations.
- **Transparent Membership Pricing:** Monthly vs. Annual toggle with -20% automated discount computation across three tiers (*Starter*, *Pro Beast*, *VIP Elite*).
- **Elite Coaching Showcase:** Master trainers profiles, bios, credentials, and specialties.
- **Contact & Inquiry System:** Working contact form saving leads to local state with instant notifications, integrated FAQ accordion, and location details.

### 📊 2. Admin Gym Management System (The Dashboard)
- **Real-Time KPI Dashboard:**
  - Total members count (+% growth trend).
  - Active subscriptions tracking with percentage health indicator.
  - Expired / Attention alert counter.
  - Estimated Monthly Run Rate ($).
  - Today's live turnstile check-ins.
- **Front-Desk Quick Check-In:**
  - Lightning-fast search by Member ID (`GYM-801`) or name.
  - 1-click check-in logging with timestamped attendance logs and expiration checks.
- **Membership Registration & Modification:**
  - Full modal form to register athletes with plan tiers, custom duration, trainer assignment, emergency contact, and automated expiry date generation.
- **Subscription Expiry Watchlist:**
  - Dedicated alert drawer highlighting memberships expiring within 7 days.
  - 1-click renewal dialog (+1 Month, +3 Months, +12 Months).
- **Interactive Visual Analytics:**
  - Canvas-rendered Weekly Footfall & Attendance chart (Mon–Sun).
  - Membership Plan breakdown donut chart.
- **Data Export & Portability:**
  - Export all members data directly into `.csv` spreadsheet format for Excel / Google Sheets.
  - One-click restore to sample demo dataset.

## 🎨 Tech Stack & Design Architecture

- **UI Framework:** HTML5, Modern Semantic Structure.
- **Styling Engine:** Tailwind CSS with custom athletic color palette (Neon Lime `#bef264`, Fiery Orange `#f97316`, Deep Obsidian `#0a0c10`).
- **Icons & Graphics:** Clean inline SVGs, CSS pulse badges, and glassmorphic panels.
- **Data Persistence:** Browser `LocalStorage` with realistic pre-populated gym athlete dataset.
- **Chart Visualizations:** Native high-performance HTML5 Canvas custom charts with retina DPR scaling.
- **Zero-Dependency Runtime:** Runs instantly in any modern browser without complex build steps or node server requirements.

## 🚀 Quick Start / Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tareq612345/gym-management-system.git
   cd gym-management-system
   ```

2. **Open directly in browser:**
   Simply double click `index.html` or run a local server:
   ```bash
   # Using Python
   python -m http.server 3000

   # Or using Node
   npx serve .
   ```

3. **Navigate the views:**
   - **Public Website:** `http://localhost:3000/#public`
   - **Admin Management Console:** `http://localhost:3000/#dashboard`
